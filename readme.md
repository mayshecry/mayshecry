## About Me

I've been coding since **2019** and I'm completely self-taught.

I started out with **Java**, but eventually got more interested in what happens closer to the machine. Since then, most of my time has gone into **systems programming, compilers, operating systems, and performance**.

I like understanding how things actually work instead of just using abstractions without knowing what's underneath them. That usually means spending way too much time reading source code, debugging weird crashes, and figuring out why something is 2% slower than it should be.

Most of my work is in **C++, C, Rust, and Go**.

## What I Work On

* Compilers and programming languages
* Operating systems and low-level tooling
* Performance-critical software
* Concurrent and distributed systems
* Networking and backend infrastructure

One of my bigger side projects is **SHS (SharkScript)**, a programming language I'm building from scratch. It's mostly an excuse to learn more about language design, compilers, runtimes, and all the fun problems that come with them.

## Outside of Code

I play a lot of **VR games**.

I also watch a lot of documentaries. Pretty much anything can get my attention if it looks interesting enough — technology, science, history, or some completely random topic I knew nothing about five minutes ago.

Most of the time, I'm just messing around with something, trying to figure out how it works, and seeing where it goes.

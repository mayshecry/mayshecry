## About Me

I've been coding since **2019** and I'm completely self-taught.

I started out with **Java**, but eventually got more interested in what happens closer to the machine. Since then, most of my time has gone into **systems programming, compilers, operating systems, and performance**.

I'm also **extremely lazy when I don't care about something**. If I find something interesting, though, that's a completely different story. I'll happily spend ridiculous amounts of time digging into a problem, reading source code, debugging weird crashes, or optimizing something nobody asked me to optimize.

I like understanding how things actually work instead of just using abstractions without knowing what's underneath them. Most of my work is in **C++, C, Rust, and Go**.

## My Completely Unnecessary Opinions

I regularly shit on **vibecoding**.

AI is a **tool**, not a programmer.

I'm perfectly fine with using AI to help write code, explain something, find bugs, or speed up development. But if you can't understand the code you're shipping without asking an AI what it does, you're not really programming — you're just operating a very expensive autocomplete.

**Use the tool. Don't become the tool.**
